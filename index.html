Import Massal Data Karyawan via Excel

Unggah file Excel (.xlsx atau .xls) dengan kolom wajib: Nama Karyawan, NIK, Departemen, dan Jabatan.

Ketentuan Validasi Otomatis:
  • Header Wajib: Nama Karyawan, NIK, Departemen, Jabatan (Opsional: Password).
  • Anti-Duplikat 2 Lapis: Sistem otomatis menolak NIK yang sudah ada di database maupun NIK ganda di dalam file Excel yang sama.
  • Auto-Create Departemen: Jika nama Departemen pada Excel belum terdaftar, sistem otomatis membuatkannya di Master Departemen.
